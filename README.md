# Tokyo itinerary static page

A single-file static web app for the Sep 18–21, 2026 Tokyo trip.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`, then save.
6. GitHub will show the public Pages URL after deployment.

No build tools, dependencies, API keys, or server are required.

The checklist and notes use browser `localStorage`, so they persist on the same browser/device but do not sync between devices.
